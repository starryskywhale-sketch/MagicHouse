# 深空魔法屋｜Deep Space Magic House

這是一個以 **深空、儀式感、溫柔日常** 為核心概念製作的品牌網站，作為 **深空魔法屋** 的展示與介紹頁面。

網站內容包含：

- 品牌主視覺與品牌故事
- 祕密商店入口式的首頁互動體驗
- 商品展示與商品詳情頁
- 店長介紹頁
- 外部購買連結（7-11賣貨便）

本網站主要作為 **品牌展示與作品介紹用途**，不提供站內購物車與結帳功能。

---

## 網站特色

- 深空宇宙感的首頁視覺
- 具有「祕密小店」氛圍的互動入口
- 隨機推薦商品／溫柔建議系統
- 商品獨立介紹頁
- 可部署於 **GitHub Pages** 的靜態網站架構
